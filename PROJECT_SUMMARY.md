## 🚀 Nasıl Başlatılır?

### Hızlı Başlangıç
```bash
./start-alfai.sh
```

### Manuel Başlatma
```bash
# Backend
cd backend && npm install && npm start

# Frontend (yeni terminal)
cd frontend && npm install && npm run dev
```

### Docker ile
```bash
docker-compose up -d
```
