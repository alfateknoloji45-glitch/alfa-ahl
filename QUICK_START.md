# ⚡ ALFAI Enterprise - Hızlı Başlangıç

## 🚀 3 Dakikada Başlat!

### Adım 1: Projeyi İndir
Dosyaları bilgisayarınıza indirin.

### Adım 2: Terminal Aç
```bash
cd alfai-enterprise
```

### Adım 3: Başlat!
```bash
./start-alfai.sh
```

Menüden **1** seçin (Full Stack) ve hazırsınız! 🎉

## 📋 Detaylı Adımlar

### Backend Başlatma
```bash
cd backend
npm install
npm start
```
✅ Backend: http://localhost:5002

### Frontend Başlatma  
```bash
cd frontend
npm install
npm run dev
```
✅ Frontend: http://localhost:5173
