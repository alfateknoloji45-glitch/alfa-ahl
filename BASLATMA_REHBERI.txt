📥 ADIM 1: DOSYALARI YERLEŞTİRİN
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

İndirdiğiniz dosyaları şu şekilde yerleştirin:

    C:\alfai-enterprise\
    │
    ├── 📁 backend\             ← Backend klasörü buraya
    ├── 📁 frontend\            ← Frontend klasörü buraya
    ├── 📄 README.md
    ├── 📄 start-windows.bat    ← ⭐ BU ÖNEMLİ!
    └── diğer .md dosyaları


🚀 ADIM 2: HIZLI BAŞLATMA (EN KOLAY)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 📁 alfai-enterprise klasörünü açın
2. 📄 start-windows.bat dosyasına ÇİFT TIKLAYIN
3. Menüden seçin:
   
   ┌─────────────────────────────────┐
   │  1) Backend                     │  ← Backend başlatır
   │  2) Frontend                    │  ← Frontend başlatır  
   │  3) Her ikisi de                │  ← 2 terminal gerekir
   └─────────────────────────────────┘

4. Tarayıcıda açın: http://localhost:5173
5. Giriş: demo / demo


🛠️ ADIM 3: MANUEL KURULUM (Alternatif)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

BACKEND İÇİN:
─────────────
1. alfai-enterprise\backend klasörüne gidin
2. Adres çubuğuna "cmd" yazın, Enter
3. Şu komutları çalıştırın:

   npm install
   copy .env.example .env
   npm start

✅ Backend hazır: http://localhost:5002


FRONTEND İÇİN:
──────────────
1. YENİ BİR CMD AÇIN (önemli!)
2. alfai-enterprise\frontend klasörüne gidin
3. Şu komutları çalıştırın:

   npm install
   copy .env.example .env
   npm run dev

✅ Frontend hazır: http://localhost:5173
